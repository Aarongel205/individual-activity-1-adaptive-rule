# Two Adaptive Rules
## Rule 1: Search Preference

If the user searches for a product or category, the system checks what category it belongs to. The preference counter for that category increases by 1.

For example, if the user searches for a sports product, the sports preference will increase by 1.

## Rule 2: Product Recommendation

If a user's preference for a category reaches at least 3 and is higher than the other categories, the system will recommend that category to the user.

For example, if the user's cooking preference is 3 and it is higher than sports, games, and appliances, the system will show cooking recommendations.
